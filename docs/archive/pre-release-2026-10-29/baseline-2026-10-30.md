## Distinguishing the kinds of check

- **Structural tests** (`backend/tests`, `frontend/src/**/*.test.*`): fake or scripted model, no network.
- **Real-model evaluation** (`eval/run.py`): live API and a real model; development measurement, tuned on the same cases.
- **Deployment drills** (`scripts/*.sh`, `docs/deployment-evidence/`): smoke test, restart persistence, Redis outage against a running stack.
