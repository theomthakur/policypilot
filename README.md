# PolicyPilot

An agentic retrieval-augmented generation (RAG) application over a set of policy PDFs. A single tool-using agent plans, searches, re-retrieves when evidence is weak, asks for clarification when a question is ambiguous, and answers with document and page citations that are verified before they are shown.

**Status:** in active development. Setup instructions, architecture, evaluation results and the deployment runbook will be added here as the work lands.

Planned stack: FastAPI, PostgreSQL + pgvector, Redis, React + TypeScript, Docker Compose, GitHub Actions.
